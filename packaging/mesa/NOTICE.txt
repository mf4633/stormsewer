Software OpenGL fallback for StormSewer on Windows
==================================================

This folder holds a build of the Mesa 3D Graphics Library (llvmpipe software
rasteriser) that StormSewer uses only when the machine has no usable GPU
driver — remote desktop without a display driver, bare virtual machines,
validation sandboxes. StormSewer.exe in this folder is a plain copy of the
one in the parent folder; it exists so that Windows loads opengl32.dll from
here instead of System32.

  opengl32.dll, libgallium_wgl.dll
    Mesa 26.2.0, MSVC build, from https://github.com/pal1000/mesa-dist-win
    (release archive mesa3d-26.2.0-release-msvc.7z, unmodified).
