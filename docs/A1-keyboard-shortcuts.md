# Appendix A. Keyboard shortcuts

SWMM workspace. Single letters and `Delete`, `Esc`, `Enter`, `F`, `F5`
work only when no text field has the keyboard; the `Ctrl` combinations
for files and undo work everywhere.

## Files and editing

| Key | Action |
| --- | --- |
| `Ctrl+N` | New SWMM model |
| `Ctrl+O` | Open .inp… |
| `Ctrl+S` | Save |
| `Ctrl+Shift+S` | Save As… |
| `Ctrl+Z` | Undo |
| `Ctrl+Y`, `Ctrl+Shift+Z` | Redo |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | Cut / Copy / Paste the selection |
| `Ctrl+A` | Select all |
| `Delete` | Delete the selection, or the chosen vertex |
| `Esc` | Cancel a profile pick; else cancel the gesture in progress; else clear the selection; else back to Select |
| `Enter` | Close the subcatchment polygon being drawn |
| `F` | Zoom to extents |
| `F5` | Run |
| `F1` | Help |

## Mouse

| Gesture | Select tool |
| --- | --- |
| Click | select |
| Shift-click | add to selection |
| Ctrl-click | toggle |
| Drag from an object | move the selection (one undo step) |
| Drag from empty space | rubber-band select |
| Click a vertex of a selected link or polygon | choose the vertex (drag it; `Delete` removes it) |
| Double-click a selected link or polygon | insert a vertex |
| Double-click an object | Properties |
| Right-click | context menu |
| Wheel | zoom at the pointer, in every tool |

## Python terminal

| Key | Action |
| --- | --- |
| `Ctrl+Enter` | Run the block |

## Storm-sewer workspace

Unchanged from earlier versions: `1`–`6` choose Select, Inlet, Junction,
Outfall, Pipe, Catchment; `F` and `G` zoom to extents and to selection;
`Ctrl+A` or `F5` analyse; `Ctrl+P` print the report; `Ctrl+Z`/`Ctrl+Y`
undo and redo; `Ctrl+O`/`Ctrl+S` open and save the project.
